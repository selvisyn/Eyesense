📖 How to Use EyeSense

1
Choose your input mode
On the start screen, tap Start Calibration for eye gaze, or Direct Entry to skip to touch mode. If you have a saved calibration, use Use Saved Calibration to continue.
👁 Eye · ☝️ Touch · 💾 Saved
2
Calibrate (Eye Gaze only)
25 dots appear one by one. Look steadily at each until the ring fills. Takes ~60 seconds. Calibration data is saved on your device.
🎯 ~60 seconds · 25 points
3
Dwell to select
Look at any button and hold your gaze. A yellow bar fills — when full the item is selected. Dwell duration is adjustable in Accessibility settings (default 1.2s).
⏱ Gaze + hold = select
4
Single blink = quick select
Enable Single Blink Select in Accessibility. With 8%+ dwell on an item, a single blink instantly selects it.
😉 Blink = select (optional)
5
Double blink = go back
Blink twice within 480ms to close the current panel and return. Works everywhere — no settings needed.
😉😉 Double blink = back
6
Iris scroll inside panels
With a panel open, move your gaze to the top or bottom edge to scroll. The deeper into the edge zone, the faster it scrolls. Works in Phrase Board, Accessibility and Smart Home panels.
↕ Top/bottom edge = scroll
7
Phrase Board
Dwell on a phrase card to speak it aloud. Dwell on the + button to add your own phrases with a custom emoji.
💬 Gaze → dwell → speaks
8
Keyboard
Dwell on each key to type. Dwell on word suggestions at the top to autocomplete. Press 🔊 to read aloud, 🎤 for voice dictation.
⌨️ Dwell-type · suggestions · TTS
9
What's Around Me?
Point your camera at your surroundings — AI describes what it sees aloud. With an API key: full visual analysis. Without: OCR text-reading mode.
👁 Scan → AI describes
10
Quick Message
Call saved contacts or send preset messages. Dwell on 📞 or 💬 to act. Customize contacts via "Edit Contacts".
📲 Ara · Mesaj Gönder
11
Smart Home
Turn devices on/off (lights, blinds, thermostat, etc.) by dwelling on their card. Fully functional in demo mode; real devices require MQTT or REST API.
🏠 Dwell = toggle device
12
Panic Button
Dwell on the red button in the top-right of the main menu. An emergency alert with your location is sent to your caregiver.
🆘 Long gaze = emergency alert
13
Tips for best accuracy
• Sit 40–55 cm from screen · • Good face lighting · • Keep head still · • Recalibrate when changing device · • Use Accessibility → Accuracy Test to check your error
💡 Distance · Light · Stillness

GAZE ESTIMATION — MATH
Iris offset (normalised gaze vector):
 rOx = (iris_x − eye_left_x) / eye_width − 0.5
 rOy = (iris_y − eye_top_y) / eye_height − 0.5
Feature vector (10-dim): f = [rOx, rOy, lOx, lOy, avg_x, avg_y, nX, nY, Δx, Δy]
Poly expand (degree-2): f' = [f, cross-terms] → 20 dims total
Ridge fit: w = (XᵀX + λI)⁻¹ Xᵀy, λ=0.001, fitted for modelX and modelY
Predict: screen_x = w⃗·[1, f']   (predict() <1ms)
Head comp: tx += yaw × W × 0.03   ty += pitch × H × 0.02
Online update: kapalı — stabil test için model kullanımda değişmez
VALIDATION & ACCURACY
Approach: Fixed 25-Point Calibration + Stable Mode (Online Learning OFF)
A fixed 5×5 grid collects 25 distributed screen points. The model is trained after all points, so edge and corner regions are represented more evenly.

Key improvements in v15:
· Fixed 25-point grid — better coverage for edge/corner drift
· Animated dot transitions — dot slides smoothly, eyes follow naturally
· Adaptive ring speed — slower for noisy/tremor users, faster for stable
· Model training only after 25/25 points — no 6/9/16 interim training
· Online learning kapalı → kullanım sırasında model kendini bozmaz
· Single blink = select, double blink = back — universal across all panels
· Iris scroll — gaze top/bottom 14% of screen scrolls active container

Limitation: Cross-user generalisability not tested. Each user must complete their own calibration.

Pilot data (n=3, laptop, normal light, 40–55 cm):
Avg. error ≈ 1.8 cm · p90 ≈ 2.7 cm · Pipeline ≈ 75 ms
Full study plan: 10–15 participants · laptop + smartphone · low/medium/bright · static + dynamic head positions.
SECURITY & PRIVACY
Camera access: WebRTC getUserMedia — browser permission dialog required on each origin.
Frame storage: Zero. Frames pass to FaceMesh and are immediately discarded.
Memory: Temporary pixel buffer (120×68 canvas) for luma sampling only.
Persistence: Only calibration model weights (modelX/Y) stored in localStorage — no biometric data.
Permission lifecycle: Camera stream released on page unload via stream.getTracks().forEach(t→t.stop()).
MOBILE / PWA PERFORMANCE
Target: Chrome Mobile / Safari iOS 16+ / Edge Android
FPS target: ≥20fps on mid-range phones (Snapdragon 778G equivalent)
CPU budget: FaceMesh uses WebGL GPU path — CPU load ~15–25%
Battery: Camera + GPU inference est. ~8–12% battery/hour
Fallback: If FPS < 15 → user prompted to close background tabs
